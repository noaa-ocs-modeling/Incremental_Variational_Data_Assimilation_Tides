This is a global test case of tides assimilation 

Please download input files input_data_GFEN2p5km300m_151/ from google drive since the file size is too big for Github: https://drive.google.com/file/d/1xjXA-MhBRLamUpR3D6yu164fu1cx6gam/view?usp=drive_link

1. Input files:

    (1) Global grid GFN2p5km_s1t6_300m_US1AK2HI1GU1_20181113_dn1_AE1.14:
        Total size: 883 K
        Min resolution: 300 m for US, AK, HI
                      2500 m for global shore.
   
    (2) Deep Ocean Bottom Pressure Recorder BPR HC data:
        bpr_v130121_cm_13_20230406.mat
                      
    (3) HxyNb_GFEN2p5km300m_151.mat is for internal tide dissipation if you use this option. It is computed by using  OceanMesh2D
    
    Other input files for each individual harmonics can be generated by a1_prepare_input_LTEs_20230330_plugin.m

3. Run tides assimilation code for the global case. It takes about half an hour for each harmonic constituent
   LTEs_BW_bohai_v03t2_20230331.m
   
   iterantion: 2;
   
   Friction: CF=8;
   
   Those infor will be saved at the output file name.
   
   output results to
   
       out_GFEN2p5km300m_151/endresults_GFEN2p5km300m_151_2it_M2_ITE1_Local2_Ae2_bs0_T2_inv1_pos2dist_Lei_CF8_C5_uvCF8.mat
   
5. Plot the result
