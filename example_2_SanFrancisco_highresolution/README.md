This is a test case for San Francisco. First tested in 2019 for 4 harmonic constituents. The data assimilation code is the same as the one in example 1 global testcase except 
(1) iteration needs set to 1000 instead of 2 as in the global testcase. 
(2) Friction CF set to 7 to match the San Francisco tide stations data better

Please download input files input_data_SFWC300s3/ from google drive since the file size is too big for Github:
https://drive.google.com/file/d/19XqEJZ5qoTDBM1P_WgpAkdPqsgM8lXt-/view?usp=drive_link


1. Input files:

(1) SFWC300s3_mergall_dbc_20190417.14:

 Total size: 222404 K
 Min resolution: 300 m for West Coast
               50 m for San Francisco Bay SCHISM grid.
               
(2) 6 Deep Ocean Bottom Pressure Recorder BPR HC data:

 bpr_v130121_cm_13_20230406.mat
 
(3) for internal tide dissipation if you use this option. It is computed by using OceanMesh2D:

HxyNb_SFWC300s3.mat

(4) Other input files for each individual harmonics can be generated by

a1_prepare_input_LTEs_20230330_plugin.m

Run tides assimilation code for the global case. It takes about half an hour for each harmonic constituent

LTEs_BW_bohai_v03t2_20230331.m
Iteration: 100;

Friction: CF=7;

Those infor will be saved at the output file name. Each harmonic takes about several minutes using one processor.

2. output results to

out_SFWC300s3/endresults_SFWC300s3_1000it_M2_ITE1_Local2_Ae2_bs0_T2_inv1_pos2dist_Lei_CF7_C5_uvCF8.mat

3. Plot the result

for all domain
  a3_SF_plotcheck_garesults_SFWC.m
